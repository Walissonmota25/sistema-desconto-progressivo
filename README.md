# Sistema de Desconto Progressivo

Este projeto foi desenvolvido para a Agenda 6 de Desenvolvimento de Sistemas I.

## Objetivo

Criar um programa em Python que calcule descontos de acordo com o valor total da compra.

## Regras de desconto

- Compras abaixo de R$ 200,00: 5% de desconto.
- Compras de R$ 200,00 até R$ 299,99: 10% de desconto.
- Compras de R$ 300,00 ou mais: 15% de desconto.

## Funcionamento

O programa solicita o valor total da compra, verifica qual desconto deve ser aplicado e calcula o valor final que o cliente deverá pagar.

## Tecnologias utilizadas

- Python
- Git
- GitHub
- Visual Studio Code

## Testes realizados

Foram realizados testes com valores abaixo de R$ 200,00, entre R$ 200,00 e R$ 299,99 e acima de R$ 300,00.
